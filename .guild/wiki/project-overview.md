# Project overview

**gnomarchi** is a greenfield Arch Linux desktop product: Omarchy’s omakase and agentic workflow, with **stock GNOME (slightly omakase’d)** instead of Hyprland + Quickshell.

The repo today holds design HTML only (no application code, no git remote). Product knowledge lives in `docs/` and is mirrored under `.guild/knowledge/sources/`.

Reference upstream: [Omarchy](https://omarchy.org/) (Arch + Hyprland + Quickshell, DHH / Basecamp).
