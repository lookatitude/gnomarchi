D1′ host model

Omarchy

Single Quickshell process: bar + menu + notifications + OSD + lock + plugins.

gnomarchi

GNOME Shell panel host + AppIndicator/StatusNotifier + optional Shell chips + GTK overlays + gnomarchi-bus + theme emitters.

Forbidden: Hyprland, Quickshell bar, SDDM. Allowed: GNOME extensions with explicit enable; GTK4/libadwaita apps; generated wallpapers.

Theme & Style UX (Omarchy parity target)

Omarchy: Appearance → Theme / Super+Ctrl+T carousel of 22 themes; each restyles desktop, terminal, nvim, btop, Chromium, shell chrome; Super+Ctrl+W cycles theme backgrounds; extras via omarchy.org/themes.

gnomarchi today: CLI/list theme picker + emitters for a subset of packs. This wave ships a GTK4/libadwaita picker with preview swatches, keyboard next/prev, menu + keybinding hooks, and a background cycle command wired into Style.

Default extensions package set

gnome-shell-extensions          # includes user-theme@…
gnome-shell-extension-appindicator
gnome-tweaks
# first-party: gnomarchi.agents-panel (+ StatusNotifier plugins)

Enable sequence (overlay post-GNOME): install → copy first-party → gnome-extensions enable / gsettings enabled-extensions → GDM restart → verify state ENABLED.
